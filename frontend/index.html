How it works

One engine, two modes

Course mode and Aptitude mode share the same generation, review, and sufficiency pipeline underneath — they differ only in who gets in, and how integrity is enforced.

Course mode pauses an attempt on tab-switch and lets the teacher resume or end it. Aptitude mode locks an attempt on fullscreen exit and only an Institution Admin can unlock it — the same underlying engine, tuned to each setting.
